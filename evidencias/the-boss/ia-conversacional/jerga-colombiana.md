# Jerga colombiana — glosario de referencia

- **Fecha:** 2026-10-11.
- **Fuente:** texto de un blog de viajes sobre palabras colombianas, pegado por Nicolás (autoría y enlace no recibidos; no se verificaron los significados). La propia fuente aclara que la jerga cambia mucho entre regiones: varias palabras son de la costa o del Valle y no se usan en Manizales.
- **Para qué sirve aquí:** entender lo que escriben los clientes y calibrar el tono del agente de The Boss (ver `prompt-v2.md`, sección «Tono y estilo de marca»). Este glosario NO se pega en el prompt.

## Guía de uso para el agente de The Boss

**Entender (los clientes pueden escribirlas):** casi todo este glosario. Ejemplos útiles en un pedido: *parce, llave, bacano, chimba, rumba/rumbear, trago, pola, filo, melona, camello, pilas, parar bolas, pedir un catorce, hacer una vaca, vaina*.

**Se puede usar con moderación (alineado al tono «el Jefe»):** *bacano, listo, con gusto, dale, pilas* (como «estar pilas»), *rumba*. El prompt ya fija jerga suave.

**No usar nunca (vulgares, ofensivas o de otro registro):** *mondá, trola, guevón/guevonada, pendejo/pendejada, verguero, despelote (en sentido vulgar), lacra, ñero, gamín, marica y derivados, piró/pirobo, toche, chichipato, mamón, cucos, whiskería, cascar, encularse, tirar los perros*. Si el cliente las usa, el agente responde normal, sin imitarlas.

**No usar con clientes nuevos (pueden sonar forzadas o confianzudas):** *parce/parcero, mijo, llave, pelao, sardino, cucho, chino, vieja/o* como trato directo.

**Ojo con «Que pena»:** en Colombia significa pedir disculpas o permiso, no tristeza. Es un buen cierre cortés: «Que pena la demora».

**«Filo» y «melona» = hambre:** un cliente que escribe «tengo un filo» está pidiendo comida; respuesta natural: «¡Listo, te lo resolvemos! 🍔».

## Acciones

| Expresión | Significado |
|---|---|
| Abrirse | Irse de alguna parte |
| Amañarse | Sentirse cómodo, acostumbrarse |
| Dar papaya | Permitir que alguien se aproveche de ti (no dar papaya = no descuidarse) |
| Camellar | Trabajar |
| Correrse | Apartarse, moverse (en España tiene otro sentido sexual) |
| Destutanarse / estutanarse | Caerse de forma poco agraciada |
| Encularse | Enamorarse u obsesionarse con algo o alguien (vulgar) |
| Embolatarse | Entretenerse haciendo otra cosa de la que se pretendía |
| Estar pilas | Estar pendiente |
| Hacer una vaca | Reunir dinero entre varios |
| Pedir un catorce | Pedir un favor |
| Manejar | Conducir |
| Ponerse las pilas | Moverse, activarse |
| Parar bolas | Poner atención: «párele bolas a eso» |
| Rumbear / rumbiar | Fiestear, o besarse con alguien |
| Tirar caja | Reír |
| Tirar los perros | Cortejar o conquistar |
| Vitriniar | Pasear por centros comerciales sin comprar |
